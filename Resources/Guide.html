Configurer en quelques minutes

  1. Place Xcode Presence.app dans Applications et ouvre-la. Retrouve ensuite ses réglages avec l’icône </> dans la barre des menus. Elle n’apparaît pas dans le Dock.
  2. Sur le portail développeur Discord, crée une application avec New Application. Nomme-la Xcode, puis copie son Application ID dans General Information.
  3. Dans la page Connexion, colle l’identifiant et clique sur Enregistrer. La fenêtre reste ouverte pour montrer l’étape suivante.
  4. Choisis Autoriser l’accès à Xcode…, puis active Xcode Presence dans Confidentialité et sécurité → Accessibilité. Ajoute l’application avec + si nécessaire.
  5. Ouvre Discord pour Mac, active son partage d’activité, puis ouvre un fichier enregistré dans Xcode. L’activité se met à jour automatiquement.

Français ou anglais

Dans Réglages → Langue de l’application, choisis Français, English ou Automatique (macOS). Le choix est conservé et traduit immédiatement les menus, les paramètres et les textes de la présence Discord.

To use English, open Settings → App language → English. The change applies immediately to the app and your Discord activity. Automatic mode follows your supported macOS language preferences and falls back to English.

Tu contrôles ce qui apparaît

La page Partage permet de masquer séparément le fichier, le projet, le langage et la durée. « Mettre en pause » retire l’activité. La pause pour inactivité est désactivée par défaut (Jamais). Tu peux choisir 5, 15 ou 30 minutes. Le compteur conserve le début de la session Xcode lors des pauses et reconnexions ; il inclut le temps passé en pause. Xcode et Xcode Beta sont pris en charge. Dans Agentic Coding ou un panneau sans document, le dernier fichier reste partagé jusqu’à la sélection d’un autre fichier. Il est oublié à la fermeture de Xcode ; les réglages de pause restent applicables.

Sources et sauvegarde

Le dépôt contient les sources Swift, les tests et les scripts de compilation. Consulte README.md pour l’installation et les instructions de développement. Conserve ce dossier et son archive ZIP ; utilise scripts/backup-sources.sh après une modification.

Si rien n’apparaît

Choisis « Ouvrir les réglages… » dans le menu. La page Ton activité indique le fichier détecté, l’autorisation macOS et la dernière confirmation reçue de Discord. Vérifie l’Application ID, l’autorisation Accessibilité, l’ouverture de Discord pour Mac et ses réglages de partage. Certaines vues Xcode n’exposent pas le fichier actif ; essaie un fichier source enregistré. Si tu as remplacé l’application et que l’accès reste refusé malgré l’interrupteur, retire uniquement son entrée puis réajoute la copie d’Applications dans Accessibilité (ou Device Control and Data Access). Valide la demande directement dans macOS.

Ce qui est partagé

Le nom du projet, le nom du fichier, le langage et la durée de session. Le code source et le chemin complet ne sont jamais envoyés. L’Application ID est un identifiant public ; aucun token de compte ou de bot n’est requis.

Prototype local pour Apple Silicon et macOS 13+. Signature locale, sans notarisation pour diffusion publique.
